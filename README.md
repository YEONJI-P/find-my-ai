# 🔍 Find My AI — 내게 맞는 AI 찾기

> **"AI는 알겠는데, 나한테 맞는 게 뭔지 모르겠어요"**
>
> 직업·고민·사용 환경을 분석해 가장 적합한 AI 도구와  
> **바로 복사해서 쓸 수 있는 맞춤 프롬프트**를 제공하는 서비스

---

## 🎯 서비스 소개

AI 도구가 쏟아지는 시대, 정작 일반 대중은 어디서 어떻게 시작해야 할지 몰라 막막함을 느낍니다.  
**Find My AI**는 MBTI 테스트처럼 가볍고 재미있는 설문(약 2분)으로 사용자의 상황에 최적화된 AI를 추천하고,  
해당 도구에서 **바로 복사해 쓸 수 있는 초개인화 프롬프트**까지 자동 생성해줍니다.

### 타겟 사용자

- AI 사용 경험이 없거나 적은 일반 대중 (시니어, 자영업자, 현장직 등)
- 어떤 AI를 어떻게 써야 할지 막막한 직장인·취준생
- AI 도구 선택에 피로감을 느끼는 N잡러·프리랜서·주부

> 💡 개발자·데이터 분석가 등 IT 직군은 서비스 특성상 별도 **이스터에그 화면**으로 안내됩니다.

## ✨ 핵심 기능

### 1. 동적 설문 (Decision Tree)
직업 대분류 → 세부 직종 → 꼬리 질문으로 이어지는 2단계 분기 구조.  
화면당 최대 5개 선택지, 총 8문항으로 완주율을 높입니다.

### 2. AI 도구 매칭
설문 응답 기반 가중치 로직(직업 30% + 세부직종 20% + 꼬리질문 20% + 기기 15% + 디지털편의도 15%)으로  
9개 AI 중 최적 도구 Top 3 추천.  
**"왜 이 AI가 나한테 맞는지"** 이유를 함께 제공하여 신뢰도 확보.

### 3. 맞춤 프롬프트 자동 생성
주관식으로 입력한 '요즘 고민'을 Gemini API에 전달하여,  
추천된 AI에서 **바로 복사·붙여넣기 가능한** 맞춤형 프롬프트를 실시간 스트리밍으로 생성.

### 4. 결과 공유
카카오톡 공유 / 링크 복사로 지인에게 손쉽게 전달 가능.

### 5. 🥚 개발자 이스터에그
직업군에서 IT·개발·데이터를 선택하면 별도 페이지로 분기.  
서비스 특성에 맞는 유머러스한 메시지로 바이럴 포인트를 만듭니다.

## ❓ 설문 구성 (8문항)

```
Q1. 나이대                  [필수] 단일 선택 (10대 ~ 50대+)
Q2. 직업 대분류              [필수] 그리드 선택 (8개 카테고리)
      └─ IT·개발·데이터 선택 시 → 🥚 이스터에그 페이지로 분기
Q3. 직업 세부 직종            [필수] 대분류별 3~4개 선택지
Q4. 직업 꼬리질문             [필수] 세부 직종 기반 분기 (업무·고민 심화)
Q5. 주 사용 기기              [필수] 스마트폰 전용 / 혼용 / PC 주력
Q6. 디지털 편의도             [필수] "앱 설치가 편한가요?" 수준의 평이한 표현
Q7. MBTI                    [선택] 무응답 허용, 결과에 한 줄 반영
Q8. 요즘 가장 큰 고민         [선택] 주관식 + 직업 연동 placeholder 자동 제공 (미입력 시 기본 프롬프트 제공)
```

> 질문 흐름 및 선택지 전체는 `/data/questions.json`에서 관리됩니다.

## 🏗 시스템 아키텍처

```
[Client: Next.js]
     │
     │  설문 응답 submit
     ▼
[Server Action]
     ├── ① 객관식 데이터 → 매칭 로직 (JSON 인메모리, 즉시 처리)
     └── ② 주관식 고민   → Gemini API (Streaming, 2~4초)
                              │
                              ▼
                     [결과 조합 → Client로 스트리밍 반환]
```

**⚡ 응답 속도 전략**
- 객관식 매칭은 JSON 인메모리 처리로 **즉시** 반환
- Gemini 프롬프트 생성은 **Streaming** 방식으로 첫 글자부터 화면에 출력 → 체감 대기 시간 최소화
- 로딩 중 동적 애니메이션으로 이탈 방지

### Lilys AI vs Gemini — 포지셔닝 분리 문제

두 도구 모두 "영상·링크 요약"에 강점이 있어 점수가 겹치는 케이스가 발생함. 실제 사용 경험의 차이는 아래와 같음.

| 구분 | Lilys AI | Gemini |
|------|----------|--------|
| **핵심 UX** | 링크 → 결과 (Link-to-Result) | 영상 기반 대화·추가 질문 (Chat-with-Video) |
| **강점** | 카톡 공유·모바일 붙여넣기 최적화, 타임라인 요약 | 구글 Docs·Gmail 연동, 보고서 작성으로 확장 가능 |
| **대상 리터러시** | 입문자 특화 — 가입 없이 즉시 사용 가능 | 숙련자 특화 — 구글 계정 필수, 프롬프트 활용 능력 필요 |
| **주요 연령대** | 4050+, "복잡한 거 싫은" 사용자 | 2030 파워유저, 정보를 가공하는 사용자 |

**향후 과제:** 현재 가중치만으로는 두 도구가 같은 케이스에서 경쟁함. 아래 방향으로 분리 전략 보강 필요.

- **follow_up 질문 보강** — "단순 요약"은 Lilys, "요약 후 문서화·분석"은 Gemini로 유도하는 선택지 추가
- **기기 환경 차별화** — Mobile Only: Lilys 가중치 우선 / PC Main: Gemini 가중치 우선 (현재 부분 반영됨)
- **연령 보정** — 50대+ Lilys 보너스 / 2030 구글 생태계 보너스로 포지셔닝 분리 강화

---

### 가중치 튜닝의 한계

- 현재 가중치는 **설계자의 판단** 기반이며, 실사용 데이터 피드백 루프가 없음
- 동일 직군 내에서도 사용 목적이 다를 수 있어 단일 가중치로 모두 커버하기 어려움
- **향후 검토:** Vercel Analytics로 "결과 페이지에서 어떤 AI가 자주 나오는지"를 모니터링하고, 특정 조합에서 편향이 발생하면 가중치 재조정

---

### MBTI 수집 후 미활용

- 설문에서 MBTI를 수집하지만 현재 점수 계산에 반영되지 않음 (프롬프트 생성 컨텍스트로만 사용)
- 도구 추천 신뢰도 저하 방지를 위해 의도적으로 배제한 결정이나, 추후 "창작 성향(N) → Claude / 효율 성향(J) → Copilot" 같은 미세 보정 가능성은 열려 있음

---

### interest_keywords 자동 분기 신뢰도

- "잘 모르겠어요" 선택 시 키워드 선택으로 업무/일상 트랙을 자동 분기하는 로직은 단순 카운팅 방식
- 선택 수가 동률이거나 `just_curious`만 선택한 경우 일상 트랙으로 fallback — 실제로 더 적합한 분기인지 검증 필요

---

### 주관식 고민 입력의 Optional 전환 및 대응 로직

사용자가 "요즘 고민"을 직접 타이핑하는 것에 부담을 느낄 수 있으므로, 이를 **필수(Required)에서 선택(Optional)**으로 변경함. MBTI처럼 입력하면 더 정교한 결과를 얻을 수 있지만, 건너뛰더라도 서비스 이용에 지장이 없도록 설계.

- **미입력 또는 의미 없는 입력 처리**:
  - `lib/gemini-prompt.ts`의 `detectConcernType` 로직을 활용.
  - 아무것도 입력하지 않거나(Type 3: 무관심/탐색형), "로또", "잠이나 자고 싶다" 등의 엉뚱한 입력(Type 5: 유머/탈출형)이 들어올 경우 Gemini API가 이를 감지하여 해당 상황에 맞는 유연한 프롬프트를 생성하도록 유도.
  - 이를 위해 결과 페이지 진입 시 Gemini API와의 연동이 필수적이며, 입력값의 품질에 따라 시스템 프롬프트(System Instruction)를 동적으로 변경하여 대응함.

### MBTI 데이터의 활용 목적 명시

- 설문에 포함된 MBTI 선택은 사용자의 흥미 유발을 위한 **'재미 요소(For Fun)'**임을 명시함.
- 추천 결과의 신뢰도를 결정짓는 핵심 지표라기보다는, 결과 리포트에서 "당신처럼 신중한(ISTJ) 사람에게는 이 도구가 딱이죠"와 같은 개인화된 멘트를 덧붙여주는 보조적인 수단으로 활용.
