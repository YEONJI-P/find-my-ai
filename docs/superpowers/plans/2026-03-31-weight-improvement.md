# AI 매칭 가중치 정밀 개선안 (2026-03-31)

## 1. 개요
초기 시뮬레이션 결과 발견된 특정 직업군 및 연령대의 추천 편향성을 해결하고, 현실적인 직업별 업무 환경(PC 사용 여부, 이동성, 언어 장벽 등)을 반영한 가중치 조정안임.

## 2. 직업군별 정밀 분석 및 조정 방향

### 2.1 자영업자 (Self-Employed Owner)
- **현상:** 자영업자 = 인터넷 홍보(Canva AI)로 획일화된 매칭.
- **현실:** 50대 요식업자에게는 SNS 홍보보다 신메뉴 레시피 요약, 로컬 정보(네이버), 세무/노무 정보 검색이 더 실질적인 니즈임.
- **조정:**
    - `self_employed_owner` + `food`: Canva AI 가중치 하향(5 -> 3), CLOVA X 및 Lilys AI 상향.
    - `digital_literacy`가 'beginner'인 경우, 복잡한 편집 툴인 Canva보다 요약/대화형 툴에 가중치 부여.

### 2.2 직장인 (Office Worker) & MS Copilot
- **현상:** 사무직 외에도 PC 사용 시 코파일럿이 상위 노출.
- **현실:** 엑셀/PPT를 쓰지 않는 직업군에게 윈도우 통합 환경은 오히려 번거로운 경험일 수 있음.
- **조정:**
    - MS Copilot의 기본 가중치를 `office_worker` 직군에 한정하여 높게 유지.
    - 타 직군에서는 `follow_up`에서 '문서/데이터'를 직접 선택한 경우에만 추천되도록 수정.

### 2.3 현장직 (Field Worker) 구체화
- **현상:** '현장'이라는 포괄적 단어로 인해 실질적 니즈 반영 미흡.
- **현실:**
    - **건설/제조:** 안전 매뉴얼 요약(Lilys), 외국인 노동자 소통(ChatGPT 번역/음성).
    - **서비스/돌봄:** 고객 응대 문구(Clova X), 관련 법규 검색(Perplexity).
- **조정:**
    - 현장직 특성상 '이동성'과 '음성 사용'이 중요하므로 Mobile 중심 AI와 음성 성능이 좋은 AI(ChatGPT, Clova X) 가중치 강화.
    - 긴 매뉴얼을 빠르게 파악해야 하는 니즈를 반영하여 Lilys AI 가중치 유지 및 강화.

## 3. 알고리즘 수정 상세 (matching-rules.json 기준)

| 구분 | 대상 | 기존 로직 | 변경 로직 (안) | 사유 |
| :--- | :--- | :--- | :--- | :--- |
| **MBTI** | 전체 | 보정치 존재 | **완전 배제** | 도구 추천 신뢰도 저하 방지 (프롬프트 요소로만 사용) |
| **연령** | 50대+ | - | Lilys AI, Clova X 보너스 강화 | 접근성 및 한국어 인터페이스 중요도 반영 |
| **직종** | 요식업 | Canva(5) | CLOVA X(5), Lilys(4) | 실질적 운영 정보 및 요약 니즈 반영 |
| **기기** | Mobile Only | - | ChatGPT, Lilys AI 가중치 상향 | 이동 중 빠른 확인 및 음성 대화 고려 |

## 4. 향후 조치 사항
- `matching-rules.json`의 가중치 수치를 위 분석에 맞춰 업데이트.
- 업데이트 후 100회 시뮬레이션을 재실행하여 '50대 요식업 사장님' 케이스에서 Canva 대신 실무형 도구가 나오는지 검증.
